워크라인 북마클릿 설치

워크라인(workline.kr) 화면에서 데이터를 바로 가져오기 위한 북마크 버튼 · ← 쿠폰 등록관리로 돌아가기

1단계진단 북마크 설치

  1. 북마크바가 안 보이면 Ctrl+Shift+B 를 눌러 켜주세요.
  2. 아래 파란 버튼을 마우스로 끌어서 북마크바에 놓으세요. (클릭 X, 드래그 O)
불러오는 중…
이 버튼은 워크라인 화면에서 눌러야 동작해요. 여기서 누르면 아무 일도 안 일어나요.

2단계워크라인에서 실행

  1. workline.kr 에 로그인 → 평소 엑셀 다운로드 받던 개통 목록 화면으로 이동
  2. 평소처럼 기간 등 조건 넣고 조회까지 해서 목록이 화면에 보이게 해주세요.
  3. 북마크바의 「워크라인 진단」을 클릭 → 결과 창이 뜨면 「전체 복사」
  4. Claude 대화창에 그대로 붙여넣기 해주세요.

진단 결과에 담기는 것

  • 화면 주소, 표의 컬럼 이름과 행 수, 샘플 3줄 (숫자는 #, 고객명·연락처 등은 ○ 로 가림)
  • 엑셀 다운로드 버튼이 내부적으로 어떤 주소/함수를 부르는지
  • 화면이 사용하는 그리드(표) 종류, 데이터 요청 주소
로그인 정보·비밀번호는 수집하지 않고, 어디로도 전송하지 않아요. 결과는 화면에만 표시되고, 붙여넣기는 직접 하시는 거예요.
